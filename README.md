# Local LLM Chat

> **AI disclaimer:** Most of the code and documentation in this project was
> generated by AI coding agents powered by large language models (LLMs).

Minimal Ollama chat UI with a Python standard-library backend and vanilla HTML,
CSS, and JavaScript. `uv` manages the project; there are no runtime dependencies
or build steps.

## Run

From this directory:

```bash
sudo systemctl start ollama
ollama list
uv run python app.py
```

If no model is installed, run `ollama pull gemma3:4b`. Open
<http://127.0.0.1:3000>.

## Tailscale access

Keep the app running after disconnecting SSH:

```bash
tmux new -s local-llm
uv run python app.py
```

Detach with `Ctrl+B`, then `D`. In another SSH session:

```bash
sudo tailscale serve --bg http://127.0.0.1:3000
sudo tailscale serve status
```

Open the HTTPS URL printed by Tailscale from another device in the tailnet. Do
not use Tailscale Funnel: the app has no authentication and must remain private.
