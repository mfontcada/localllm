# Local LLM Chat

> **AI disclaimer:** Most of the code and documentation in this project was
> generated by AI coding agents powered by large language models (LLMs).

Minimal, local-first chat UI with an `aiohttp` backend and vanilla HTML, CSS,
and JavaScript. It streams text from Ollama and supports optional realtime
voice input through NVIDIA NeMo-Speech.cpp. Audio stays local and is not saved.

## Stack

- **Ollama** serves the chat models on `127.0.0.1:11434`.
- **NeMo-Speech.cpp** serves Nemotron 3.5 ASR on `127.0.0.1:8080`.
- **Local LLM Chat** proxies both services and serves the UI on
  `127.0.0.1:3000`.

For installation, model sizing, verification, persistent sessions, Tailscale,
and troubleshooting, follow the [full stack setup guide](docs/setup.md).

## Quick start

This assumes Ollama, at least one Ollama model, NeMo-Speech.cpp, Nemotron 3.5,
and `uv` are already installed.

Start Ollama:

```bash
sudo systemctl start ollama
ollama list
```

Start the speech service in a second terminal:

```bash
nemo-speech serve \
  --asr-model nemotron-3.5 \
  --gpu 0 \
  --host 127.0.0.1 \
  --port 8080 \
  --no-ui
```

Start the app from this directory in a third terminal:

```bash
uv run --frozen python app.py
```

Open <http://127.0.0.1:3000>. The Mic button becomes available automatically
when NeMo is ready. Use `Alt+M` to start or stop voice input, or `Escape` to
stop it. Voice options can leave the transcript for review or send it
automatically, and can optionally stop after a pause. Open the sliders icon
beside Mic to change these options. Text chat remains available when NeMo is
stopped.

## Private remote access

The app can be published privately over Tailscale HTTPS:

```bash
sudo tailscale serve --bg http://127.0.0.1:3000
sudo tailscale serve status
```

Do not use Tailscale Funnel: the app has no authentication and must remain
private. See the [setup guide](docs/setup.md#private-remote-access) for the full
procedure.
